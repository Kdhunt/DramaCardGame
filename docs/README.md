## Reading the status of an idea

* User requirement means something the user explicitly requested.
* Current direction means the latest interpretation of those requirements.
* Proposal means an assistant suggestion that still needs design decisions or playtesting.
* Superseded means an earlier suggestion replaced by later user guidance.
* Implemented means verified in the reviewed source snapshot, not merely described on a card or in the rules page.
* Verified calculation means a mathematical or isolated code check. It does not mean people have playtested the game.

The user's latest clarification governs this review: permanent main characters, cards that affect other cards, a satisfying run of interference by several players, escalating drama, and different players benefiting for different reasons. Munchkin's encounter interference is the comparison. Poker hand rankings, betting, and fixed contribution awards are not the design direction.

These additions document the research. They do not change application behavior or deploy revised game mechanics.
